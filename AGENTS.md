# Instructions for coding agents

Read `HANDOFF.md` first. It is the current state of the project, the rules, and the
workflows. `docs/METHODOLOGY.md` explains the evidence model in depth and
`docs/PLAN-2026-09.md` is the approved plan behind the September phases.

ChatGPT and Claude both work in this repository. After a material change, update
`HANDOFF.md` with what changed, the evidence or decisions, verification results,
remaining work, and the commit or deliverable location. Keep `README.md` figures in
sync, and update these agent instructions when a lasting workflow rule changes.
Commit the handoff update with the work so the next agent reads the current state.

Hard rules, in short:

- Every address-to-entity attribution needs the address's own explorer page showing a
  public name tag. No guessing, no third-party compilations. Store the tag verbatim.
- Never add deposit addresses, funders, routers, bridges, token contracts or issuer
  treasuries to the registry. Never bypass explorer CAPTCHAs.
- `lib/atlas/known-addresses.ts` is generated. Edit `scripts/registry/addresses.txt`,
  run `probe-code.mjs` then `gen-addresses.mjs`, and let the generator refuse orphans.
- `node scripts/verify-all.mjs` must pass before any build. `pnpm build:live` is gated on
  it; do not remove the gate or weaken a failing assertion. Since 2026-10-18 it ends with `tsc --noEmit` over
  the whole project, so a type error in the UI fails the gate too (`pnpm typecheck` runs that step alone;
  `pnpm dev:live` is the dev server). Node 22.18 or newer: the build-time renderers import `.ts` from `.mjs`.
- The live build is static and keyless. Do not add a server, runtime env vars or API keys.
- The observed-onchain figure is a declared sample. Never scale it up.
- Lint has 34 pre-existing errors and 6 warnings (`pnpm lint`, recounted 2026-10-18 under the typescript-eslint and
  react-hooks presets; HANDOFF section 29). Do not add to that count.
- `dist-live/llms.txt` and `methodology.md` are generated by the build from `live-lite/llms.txt.tpl`, `docs/METHODOLOGY.md`
  and the code (HANDOFF section 18). If you reword a page sentence the template quotes, rename a UI term, add a chain,
  retune `UNLOCK_SHARE` or make the page read the URL, `verify-llms.mjs` fails until the template and the docs agree. Do not
  type a number into the template prose; stamp it in `scripts/llms/render.mjs`. Never put a copy in `public/`.
- The Landmarks page (`landmarks.html`, HANDOFF section 19) names a party only under decision D7: an explorer tag
  the explorer credits to no outside source, a primary document that identifies the address or transaction, or a
  description that a complete read matches to exactly one transaction. News and analytics firms never name anyone;
  a person is named only on their own statement or a court record of conviction or plea. Its names never enter the
  registry. `lib/landmarks/data.ts` is generated: edit `scripts/landmarks/entries/`, run `fetch-facts.mjs` then
  `gen-landmarks.mjs`. Its recent window moves monthly (`scripts/landmarks/README.md`). A tag with any third-party
  credit (a compilation, a report, "Submitted by ...") names nobody there, nor does one read on Arbiscan or Optimistic
  Etherscan (their readable page hides the banners). A leg that `follows` another is told but never added to a total.
- Edit files containing backticks or `$` with the Edit tool or a script file, never with `node -e "..."` in bash:
  double quotes run backtick text as commands and eat `$`, silently (it happened twice on 2026-10-02).
- Read explorer tags with `scripts/registry/read-tag.mjs` (logic in `tag-reader.mjs`). Before 2026-10-02 it missed
  compilation disclosures whose name was a link; registry notes written before then may lack one.
- No synthetic data, ever. Everything shown must be real, live or recent. Never fall back
  to simulated values when a feed fails; show the honest health state. (`lib/atlas/engine.ts` is the live
  accounting, not a demo; the demo engine was removed on 2026-09-21.)
- Add as much real data and as many sources as free APIs and public endpoints allow. When
  free sources are running out (rate limits, key-only chains, exhausted labels), stop and
  tell Jake which free/paid APIs to get and what each unlocks. He signs up himself.
- The project's own links (author, site, repository, LinkedIn) live in `lib/site/links.ts`; the page, the Landmarks
  renderer and the llms build all read them from there. The link-preview image `public/og.jpg` is cartography only and
  is re-captured with `scripts/og/capture-snippet.js` on the dev server after a design change to the globe (HANDOFF
  section 31); never put a route or a figure in it.
- Commit as `git -c user.email="223131039+jakeperc@users.noreply.github.com" -c user.name="Jake Percy"`.

Deliverable for Jake is a zip of `dist-live/` that he FTPs into a folder under
`public_html` on jakepercy.com.
