What you're looking at

This is a lightweight, backend-free companion to Ledger Atlas. It reads real Ethereum mainnet USDC and USDT transfers directly from your browser, using free public endpoints, and draws a route only when both ends of a transfer touch a specific wallet this project has publicly documented evidence for.

What's genuinely live

Transfer counts, totals and evidenced routes are real, current chain activity, polled roughly every 20 seconds from a public Ethereum RPC endpoint. Prices come from CoinGecko's public API.

What this page deliberately does not do

It has no server and no database, so it has no memory beyond your current browser tab: only a 5-minute or 1-hour rolling window is available, there is no 24-hour or 7-day view, and there is no historical baseline or anomaly detection. Refreshing the page starts over. The full Ledger Atlas map (with longer windows and trend history) needs a small persistent backend — this page is the free, no-backend preview of it.

Why most transfers show as unresolved

A wallet address has no inherent physical location. This page only assigns a jurisdiction when it has a specific, sourced, public reason to — a small hand-curated list of major exchange wallets, each with a citation. Every other transfer is real value moving on Ethereum with genuinely no public evidence of who controls either end, so it is intentionally left unresolved rather than guessed.

Sources

Ethereum data: a free public JSON-RPC endpoint (no API key). Prices: CoinGecko's public API. Geography: Natural Earth via world-atlas (public domain). Wallet evidence: see known-entities.js shipped alongside this page, which lists a source URL for every entry.
