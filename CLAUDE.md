# Claude project instructions

Read `AGENTS.md` and `HANDOFF.md` before working in this repository. `HANDOFF.md`
is the shared current state for Claude and ChatGPT, including project rules,
recent changes, evidence, verification, and remaining work. Follow its links to
`docs/METHODOLOGY.md` and the relevant measurement reports when changing the registry.

After a material code, data, evidence, or deployment change, update `HANDOFF.md`
in the same commit. Include what changed, verification results, unresolved work,
and any build or zip deliverable. Keep the short status in `README.md` synchronized.
Do not rely on a prior chat as the sole handoff to the next agent.
